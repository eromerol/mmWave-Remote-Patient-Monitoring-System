# mmWave Remote Patient Monitoring System

Master's Thesis project focused on the design, implementation and validation of a non-invasive remote patient monitoring system using 60 GHz mmWave radar technology.

## Features

- Heart rate monitoring (BPM)
- Respiratory rate monitoring (RPM)
- Distance estimation
- MQTT communication
- Home Assistant OS integration
- Historical data storage
- Trend analysis
- Alarm generation
- Remote dashboard visualization

## Hardware

- Seeed Studio MR60BHA2
- XIAO ESP32-C6
- Raspberry Pi 3
- LCD Touchscreen

## Software

- Arduino IDE (C++)
- Home Assistant OS
